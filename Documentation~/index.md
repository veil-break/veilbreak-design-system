# Veilbreak GUI documentation

`com.veilbreak.gui` is the Veilbreak interface: the Veil theme's tokens, fonts and icons, and a UI Toolkit kit for
portrait battle HUDs and menus. It is also the source of the Veilbreak Design System artifact, which is rebuilt from
this folder.

## Quick start

1. Reference the package and use `Runtime/Settings/VeilbreakPortrait.asset` as the panel settings.
2. Give the root element the class `vb-root` and wrap it in a `SafeAreaRoot`.
3. Bind view models to components every frame.
4. Import the **BattleHud** sample (Package Manager → Samples) to see a whole board with fake data. Import **Gallery**
   to see every component in its main states.
