# Consumer integration

Call IntroSplash.Play(host, reducedMotionOrFlashes). It consumes skip input and detaches at 4.33 seconds; reduced mode fades the final mark. Call Stop on an explicit teardown. Pinned is only for captures. The original path geometry and phase timing are adapted from Veilbreak; portrait framing fits essential geometry. No arcade, roster or sibling navigation assembly is required.

Supply all dependencies explicitly. Runtime packages must compile without Assets/_Arcade, an ArcadeApp singleton, or access to a sibling checkout. The arcade simulation package intentionally exposes its game-specific rules.
