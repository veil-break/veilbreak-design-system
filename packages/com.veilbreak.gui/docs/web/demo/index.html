VEILBREAK WEB APP

Every pixel in the phone is a @veilbreak/gui view, the React twin of the Unity package's views. The app only holds state and answers events, the same way a Unity game binds view models.

  • Menu → Squad (pick four) → Battle
  • Pause (Esc or the pause square) → Settings, Abandon (confirms)
  • Clear a wave to draft a perk; lose everyone to see results and scores
