# com.veilbreak.feedback

Create FeedbackPool with an explicitly supplied additive material. Submit FeedbackRequest payloads and Advance(simulationDelta). CueCatalog maps presentation keys (event kinds, skill shapes, per-skill rows) to a set piece, its strength, mark, light, shake, sound, priority and pulse. ProjectedReadouts receives projected actor positions and health; it never queries a game singleton. Register CinematicPulseFeature in the URP renderer, assign its shader, and drive the CinematicPulse VolumeComponent from the consumer. The URP and UI adapters have separate assembly boundaries.

For combat effects, add EffectEmitters and call Initialize(additive, alpha, high) with two FeedbackParticle.shader materials over Runtime/Textures/T_FxAtlas.png (additive: SrcAlpha/One; alpha: SrcAlpha/OneMinusSrcAlpha). Play(routine, FxCall, priority) plays a set piece; Drift(metres) slides the effect space with your road; Advance(simulationDelta) each frame. Priority 2 and above always plays, lower pieces are dropped once the frame budget (560 Standard, 190 Low particles) is spent. Parent a GroundMarks under emitters.Ground for scorch and crack marks, use QuadBatch for per-frame ground quads such as contact shadows, LightFlashes for pooled point-light flashes, and AudioVoices for cue one-shots. Regenerate the atlas and sounds with `uv run --project ../../tools python Tools~/fx_atlas.py` and `Tools~/sounds.py`; both are deterministic.

For ground telegraphs, add GroundTelegraphs, call Initialize(material using Telegraph.shader), then each frame Begin(), Draw(request) in priority order and End(). Requests are world-space circles, cones (full angle in degrees) or capsule lanes; supply your own authoritative geometry and verify it with TelegraphGeometry.Inside. Set TelegraphRequest.curtain (metres) to raise a light curtain along the outline: vertical rays and drifting dust in Telegraph.shader's second pass (LightMode UniversalForward), one shared dynamic mesh, skipping strips buried inside another footprint of the same side; TelegraphGeometry.Outline returns the rim points.

For battle surfaces (desktop-tier battle VFX, from veilbreak-main):

- `DecalPool` (Feedback.URP): add it, call `Initialize(capacity)` with the cap for your quality tier, then `Place(material, at, size, life)`. Decals project straight down, fade over the last third of their life, and the oldest goes first at the cap. Set `DrawDistance` to your camera's farthest ground view.
- `SurfaceIndicators` (Feedback.URP): plan lines projected through the world depth. Construct it with a URP decal material template, a segment cap and optionally a four-slot palette (green, red, blue, neutral). Set `Top`/`Bottom` above and below every surface, then `Begin()`, `Draw(points, width, loop, colour)` per polyline, `End()`.
- `CurtainBatch`: vertical light curtains on ground outlines in one mesh (`Begin`, `Add`, `End`; `Bake` for builders). Your curtain shader reads the global `_CurtainPhase`, which `CurtainBatch.Phase(time)` advances (0 under Reduced Motion).
- `PooledEffect.Create(prefab, parent, release)`: a one-shot prefab instance that returns itself to your `ObjectPool` through the particle Stop callback.

To draw catalogue cues without writing the sink plumbing, create a `CueStage` with your `EffectEmitters`, `GroundMarks`, `LightFlashes` and `AudioVoices` (any may be null), set `Shake` and `Pulsed` to your camera rig and flash volume, and call `Play(cue, fallbackRoutine, call, groundPoint)` per mapped event. `Punch(at, colour, strength, camera)` adds a heavy moment's screen impact and particle burst, and `CueStage.Reticle(batch, local, size, colour, time)` draws closing chevrons around a marked body. Set `ReducedFlashes` from your settings. Event mapping stays in the game.

For whole-screen hits, push confirmed impacts with ScreenImpacts.Push(viewport, colour, strength) and call ScreenImpacts.Advance(unscaledDelta) each frame; CinematicPulseFeature renders the strongest four (shockwave refraction, zoom punch, chromatic split, tinted vignette) even while no pulse volume is active. Set ScreenImpacts.Motion to 0 for Reduced Motion and ScreenImpacts.Flash to 0 for Reduced Flashes.

Assemblies: `Veilbreak.Feedback / Veilbreak.Feedback.URP / Veilbreak.Feedback.UI`. Unity 6000.3; URP adapters require URP 17.3.

Install from git with a reviewed commit, `"com.veilbreak.feedback": "https://github.com/veil-break/veilbreak-design-system.git?path=/packages/com.veilbreak.feedback#<full-reviewed-commit>"`, plus the git sources of its first-party dependencies (Unity does not resolve git dependencies declared inside packages). Veilbreak games get these entries from `vb packages remote`; use `vb packages local --package com.veilbreak.feedback` to edit this folder from a game. Moved here from veilbreak-arcade with its GUIDs unchanged.

See Samples~/Integration.md for an integration example. Engine-free regression checks are in tests/Portable in the development workspace; package-consumer validation copies packages into a clean Unity project.

Import the Minimal consumer sample from Package Manager. Package-local Editor tests are in `Tests/Editor`; enable package tests with Unity Test Framework (`testables` in the consumer manifest).

For gamma-authored interface colors in a linear world, register GammaUiFeature on the camera's URP renderer and assign GammaUi.shader. Add GammaUiPanel to the UIDocument before populating its tree. The adapter owns one full-resolution UNORM UI surface and cloned PanelSettings; the feature composites tracked world/UI inputs after world post effects. It currently supports one active screen document/Game camera, without XR. Budget the extra surface/pass on hardware.
