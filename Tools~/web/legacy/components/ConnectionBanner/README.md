# ConnectionBanner

The reconnect notice: what is happening and what it means for the match, while inputs are paused.

**Provide** nothing for the default copy; optional `title` and children to replace the body.

- Sits on `layer-modal`, centred near the top, never over the Power strip or the ability cluster.
- The match keeps running on the server; the copy says so. Remove the banner the moment a full baseline arrives.
